Prerequisite stack

  1. Client, server, database: what each one does and who may call whom.
  2. What a monorepo is. One git repo, many apps.
  3. Auth basics: OAuth login, what a session is.
  4. Queue and background job: work that runs after the request ends.
  5. What "serverless" means: you rent run time, not machines.

Open threads

  • Where is the authorization check in his stack? He never says.
  • What does one user cost him? He says he did not look.
  • "Every tool can handle scale." Which load test shows it?
  • What is the exit plan if Convex or Vercel changes price or dies?
  • How does a workflow stay safe on retry, so a user is not charged twice?
