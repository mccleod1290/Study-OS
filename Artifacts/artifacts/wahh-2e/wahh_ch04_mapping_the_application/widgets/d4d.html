POST
  • URL path (d4b, g5): the path parts are data, injected like query values.
  • query parameters (d4c, g5): fuzz each name; a different size is a live name.
  • Host (d4a, g2): one of the headers that is an entry point.
  • User-Agent (d4d, g5): trusted; a mobile User-Agent reaches less-tested code.
  • Referer (d4d, g5): trusted.
  • X-Forwarded-For (d4d, g5): trusted.
  • cookies (d4a, g2): an entry point.
  • POST fields (d4a, g2): an entry point.
  • JSON keys and nested fields (d4a, g2): not verified.
